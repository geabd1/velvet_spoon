# The Velvet Spoon

[![Figma Prototype](https://img.shields.io/badge/Figma-Prototype-FF6B6B?logo=figma)](https://www.figma.com/proto/bWbFg9KalfPvP7k6RNnahp/The-Velvet-Spoon-Prototype?node-id=42-110&starting-point-node-id=39%3A45&t=FjRqWG8DT9XVNZj9-1)

The Velvet Spoon is a recipe web application designed to provide users with easy-to-follow cooking instructions. Browse recipes freely or create an account to unlock features such as: commenting, rating, and saving recipes.

## Features

### For All Users
- **Browse recipes** without an account
- **Detailed recipe pages** with:
  - Ingredients lists
  - Step-by-step instructions
  - Preparation times
  - Serving sizes

### Account Holders
- Comment on recipes
- Rate recipes
- Save recipes to personal boards


##  Tech Stack

**Frontend:**
- HTML5
- CSS3
- JavaScript

**Backend:**
- PHP
- MySQL

**Libraries:**
- Google Fonts

## Features Not Implemented
- Multiple photos for recipes
- Forgot Password function
- Profile picture for users

## Bugs/Limitation
- When you click account settings, it says "Board created", which should not be there
- Can only change username, email, and password
